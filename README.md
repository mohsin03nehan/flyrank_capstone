# FlyRank Capstone

Capstone project for the Frontend AI Engineering internship track at FlyRank AI.

## Settings Form

This project now includes a polished React settings form with:

- profile identity fields
- notification toggles
- appearance controls
- save confirmation state
- responsive layout for desktop and smaller screens

## Run locally

```bash
npm install
npm run dev -- --host 0.0.0.0 --port 4173
```

Then open http://localhost:4173 in the browser.

## Build

```bash
npm run build
```
